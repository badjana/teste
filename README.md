# Jogo do Macaco - Pegue as Letras

Um jogo completo baseado no projeto Scratch, onde você controla um macaco que deve pegar letras que caem do céu.

## Como Jogar

1. Abra o arquivo `index.html` em seu navegador
2. Pressione **ESPAÇO** para começar o jogo
3. Use as **setas ← →** para mover o macaco horizontalmente
4. Pegue as letras que caem para ganhar pontos (3 pontos por letra)
5. Não deixe as letras tocarem o chão, ou você perderá uma vida
6. O jogo termina quando você perde todas as 3 vidas
7. Pressione **ESPAÇO** novamente para reiniciar

## Características do Jogo

- **Movimentação suave:** Controles responsivos mas não excessivamente rápidos
- **Velocidade balanceada:** Letras caem em velocidade que permite reação do jogador
- **Spawn controlado:** Letras aparecem em intervalos balanceados (não sobrecarrega)
- **Dificuldade progressiva:** Velocidade aumenta gradualmente com o tempo
- **Feedback visual e sonoro:** Som de coleta e interface clara
- **Design atrativo:** Fundo azul céu com chão verde, como no projeto Scratch original

## Tecnologias Utilizadas

- HTML5 Canvas para renderização
- JavaScript puro para lógica do jogo
- CSS3 para estilização
- Web Audio API para efeitos sonoros

## Sistema de Pontuação

- **3 pontos** por cada letra coletada
- **3 vidas** no total
- **Game Over** quando todas as vidas são perdidas
- Display em tempo real da pontuação e vidas restantes

O jogo foi cuidadosamente balanceado para ser divertido e desafiador sem ser frustrante.
